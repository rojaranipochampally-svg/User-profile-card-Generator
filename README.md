# User Profile Card Generator

A complete starter project for the Workora task. It demonstrates:
- HTML form input collection
- Server-side processing with Node.js and Express
- String cleaning, splitting and validation
- Dynamic live profile-card preview in the browser
- Server-generated HTML profile page
- Saving profile records in Supabase PostgreSQL

## 1. Requirements

Install:
1. Node.js 18 or newer: https://nodejs.org/
2. Visual Studio Code: https://code.visualstudio.com/
3. A free Supabase account: https://supabase.com/

Check Node.js and npm in VS Code Terminal:
```bash
node -v
npm -v
```

## 2. Create the Supabase database

1. Sign in to Supabase and create a new project.
2. Open **SQL Editor** in the left menu.
3. Select **New query**.
4. Open this project's `database.sql`, copy all SQL, paste it into the editor and click **Run**.
5. Open **Project Settings -> API** (or API Keys, depending on dashboard layout).
6. Copy the Project URL.
7. Copy the `service_role` secret key. Keep it private. Do not put it in `public/app.js`, GitHub, or any frontend file.

## 3. Run the project locally

1. Extract the ZIP file.
2. Open the extracted `user-profile-card-generator` folder in VS Code.
3. Open **Terminal -> New Terminal**.
4. Install dependencies:
```bash
npm install
```
5. Create a file named `.env` in the project root (same level as `server.js`).
6. Copy the following into `.env` and replace the example values:
```env
PORT=3000
SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVICE_ROLE_SECRET
```
7. Save `.env`.
8. Start the server:
```bash
npm start
```
9. Open this address in Chrome:
```text
http://localhost:3000
```

Important: Do not open `public/index.html` directly and do not use Live Server for this project. Express must run so that the `/api/profiles` backend routes work.

## 4. Test all features

1. Enter a name and a short bio.
2. Enter skills separated by commas, for example `Java, HTML, CSS, SQL`.
3. Optionally add valid GitHub, LinkedIn and portfolio URLs.
4. Confirm the preview changes while typing.
5. Click **Save profile**.
6. A success message and an **Open server-generated profile** link should appear.
7. Open the link. It should display a profile page generated by the Node.js server.
8. In Supabase, open **Table Editor -> profiles** and confirm that the record is stored.

If saving fails, check that the SQL was run and that `.env` contains the correct Project URL and service-role key. Restart the server after changing `.env` by pressing `Ctrl+C` and running `npm start` again.

## 6. Deploy the application on Render

GitHub Pages cannot host this complete project because it runs a Node.js backend. Deploy it as a Render Web Service instead.

1. Push the code to GitHub using the steps above.
2. Sign in at https://render.com/ and choose **New -> Web Service**.
3. Connect your GitHub account and select this repository.
4. Configure:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance type:** Free (if available for your account)
5. In the Render service's **Environment** settings, add:
   - `SUPABASE_URL` = your Supabase Project URL
   - `SUPABASE_SERVICE_ROLE_KEY` = your Supabase service-role secret
6. Click **Create Web Service** and wait for the deployment status to become **Live**.
7. Open the `onrender.com` URL provided by Render and test saving a profile.
8. Confirm the record appears in Supabase Table Editor.

Render may take some time to wake up on a free instance. Do not add `.env` to GitHub; set secrets in Render's Environment settings.

## 8. How the application works

1. The user enters profile details in the HTML form.
2. `app.js` listens for input events and updates the preview.
3. On submit, JavaScript sends the form data to `POST /api/profiles`.
4. `server.js` validates and cleans the values (including splitting skills by commas).
5. Express inserts the profile into the Supabase `profiles` table.
6. The server returns the saved profile ID.
7. The browser displays a link to `/api/profiles/:id`.
8. Express reads the record and builds an HTML profile page on the server.

## 9. Common errors

- **`npm is not recognized`:** Install Node.js, close and reopen VS Code, then run `node -v` and `npm -v`.
- **Database is not configured:** Check the `.env` filename and variable names. Ensure `.env` is in the root beside `server.js`.
- **Invalid API key / permission error:** Use the Supabase `service_role` secret on the server, not the publishable/anon key. Do not expose it publicly.
- **Cannot find module:** Run `npm install` from the project root.
- **Port already in use:** Change `PORT=3000` to another port such as `PORT=3001` in `.env`, then restart.
- **Changes not appearing on Render:** Push the latest commit to the connected GitHub branch and check Render deployment logs.
